# UI sound effects — Shared

These sounds belong to interface actions, not the story’s narrative SFX in `../sfx/`.

## Current interface sounds

- [x] [`choice_select.mp3`](choice_select.mp3) — soft press cue for buttons and button-like links across the home page and stories.
- [x] [`game_success.mp3`](game_success.mp3) — completion cue played when story assets reach 100%.
- [x] [`../ping_pong.mp3`](../ping_pong.mp3) — legacy cue retained for the audio toggle.

## Sourced candidates

These sourced MP3 files are available in this folder. Pixabay lists them as free under its Content License; the license allows free use and modification, but prohibits redistributing an unchanged file on a standalone basis.

- [x] `choice_select.mp3` — Soft confirmation click. [Source and download (pixabay.com)](https://pixabay.com/sound-effects/film-special-effects-soft-interface-click-126517/).
- [x] `game_success.mp3` — Short UI completion chime. [Source and download (pixabay.com)](https://pixabay.com/sound-effects/film-special-effects-ui-loading-end-success-522861/).
- [x] `neutral_retry.mp3` — Quiet neutral click; use at lower volume than selection. [Source and download (pixabay.com)](https://pixabay.com/sound-effects/film-special-effects-soft-ui-click-147352/).
- [x] `chapter_transition.mp3` — Brief airy whoosh; optional and best kept very quiet. [Source and download (pixabay.com)](https://pixabay.com/sound-effects/simple-whoosh-transition-382722/).
- [x] `panel_open_close.mp3` — Soft modal tap; can be reused for opening and closing. [Source and download (pixabay.com)](https://pixabay.com/sound-effects/film-special-effects-ui-modal-close-soft-tap-523151/).

Keep UI sounds short and quiet under narration. Never rely on sound alone to communicate success, failure, or required information.
