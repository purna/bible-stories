## Total Summary

- **25 stories** with design source of truth documents
- **251 total acts** across all stories
- Each story has 4 core documentation files:
  1. **Design Source of Truth** — Canonical visual storyboard (panel/scene direction)
  2. **Game Plan** — Chapter-level authority for playable action
  3. **Music Source of Truth** — Musical identity and chapter music map
  4. **SFX Source of Truth** — Sound effects specifications

## Visual Layout Snapshots

All design source of truth documents now include **Visual Layout Snapshots** for each act (3 panels per act: Establish, Interact, Resolve) matching the Moses reference format. Each snapshot contains ASCII art depicting:

- FG/MG/BG layers with Texture Forge keys
- UI elements (captions, speech bubbles, choice buttons)
- Camera angles and transitions

Total visual layout snapshots: **251** (one per act across all stories)
